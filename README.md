# Animal Match 🐶🐱🐸

A colourful memory-matching game for kids, built as a single web page.

- **How to play:** open `index.html` in any phone, tablet or computer browser. Tap two cards to find matching animal pairs.
- **3 levels:** Easy (3 pairs), Medium (6 pairs), Hard (10 pairs).
- **Big buttons**, cartoon animals, cheerful sounds and a spoken animal name when you find a pair (tap 🔊 to mute).
- **Private:** no ads, no sign-up, no tracking, no network requests. The only thing saved is your sound on/off choice, and it stays on your device.

No install or build step. It's just one file.
